# Casa Criativa Gestao V2

Sistema administrativo SPA para a operacao Casa Criativa.

Esta etapa entrega apenas Planejamento e Fundacao. Modulos reais como Alunos, Agenda, Mensalidades e Financeiro ainda nao foram implementados.

## Stack

- React
- TypeScript strict
- Vite
- React Router
- TanStack Query
- Supabase
- React Hook Form
- Zod
- Tailwind CSS
- Vitest
- React Testing Library
- Playwright

## Scripts

- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run test`
- `npm run build`
- `npm run e2e`
